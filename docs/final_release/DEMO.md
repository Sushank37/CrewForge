# Three-minute demo

**0:00–0:30** Show the public MCP configuration in a real assistant. Explain that the judge submits one task and receives a job ID.

**0:30–1:10** Show the approved task submission and poll its status. Cut live waiting time in the recording and label the cut. Read the final answer and show the source excerpts or unresolved items.

**1:10–1:55** Open the execution trace. Point to a recorded specialist assignment, any peer contribution, a grounded calculator result and an independent verdict. If the run has no peer objection, show the actual review evidence.

**1:55–2:30** Open the identical single-agent run. Compare actual answers and measured calls, tokens, latency and cost. Use blinded scores only once available.

**2:30–3:00** Show the optional dashboard and identify which checks are still pending. End with the public endpoint and repository link.

Record once the live allocation is approved. Use a public-safe problem, and keep keys, grading materials, private IDs and workspace tabs off screen.
